# Sorteio de amigo secreto
Olá! Este é um repositório que resolve o primeiro desafio da trilha do ![OracleOne](https://www.oracle.com/br/education/oracle-next-education/), o repositório original está ![aqui](https://github.com/Oracle-Next-Education/challenge-amigo-secreto_pt).  
## Proposta
A proposta em si é bem simples, precisamos implementar as funções no JavaScript com alguns principios da lógica, utilizando arrays para captar nomes, adicionalos a array e ao final sortear os mesmos em ordem aleatória, de maneira que eles não se repetissem.
